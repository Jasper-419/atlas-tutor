## 架构与自主取舍

- 保留 `frontend/` 与 `backend/` 两个清晰模块，前端替换为 Next.js App Router + React + TypeScript，后端为 FastAPI 模块化单体。
- PostgreSQL 是 Docker 部署主库；SQLite 是无需 Docker 的本地启动选项。数据库迁移由 Alembic 管理。
- LangGraph 负责课程规划与研究流程，持久化 checkpoint 与业务学习记录分开保存。
- 使用已有环境变量配置的 OpenAI 兼容模型，支持 DeepSeek。缺少配置或调用失败明确返回失败，不以模拟结果冒充模型功能。
- 文档使用真实解析、分块和关键词检索；配置 embedding 后启用语义检索与混合排序。私有资料始终受课程归属约束。
- 教学、练习与评估形成闭环；客观题规则评分，开放题使用 rubric；掌握度、解锁、错题、间隔复习由服务端规则控制。
- 后台任务持久化在数据库，支持进度、取消、重试和服务重启后恢复。部署提供 Redis/Celery worker，轻量本地模式提供内嵌 worker。
- 默认先交付可本地运行及 Docker 部署的代码，不代替用户购买服务器或创建公网服务。
- 视觉：安静的学习工作台，纸张色背景、深墨文字、青绿色知识路径，Atlas 路径符号；真实空状态、真实数据，无虚构指标。
